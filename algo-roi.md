# Algorithm Topics — Difficulty vs ROI

Use this to prioritize what to study next. High ROI topics show up most often in interviews and are worth mastering first.

---

## High ROI

| Topic | Difficulty to Learn |
|-------|-------------------|
| Two Pointers | Easy |
| Sliding Window | Easy |
| Breadth-First Search | Easy |
| Depth-First Search | Medium |
| Backtracking | High |

| Dynamic Programming | High |

---

## Low ROI

| Topic | Difficulty to Learn |
|-------|-------------------|
| Divide and Conquer | Medium |
| Trie | Medium |
| Union Find | Medium |
| Greedy | High |

---

## Recommended Study Order

1. Two Pointers — easy to learn, highest return
2. Sliding Window — easy to learn, highest return
3. BFS — easy to learn, highest return
4. DFS — medium difficulty, highest return
5. Backtracking — hard to learn, but highest return
6. Binary Search — easy to learn, medium return
7. Heap — medium difficulty, medium return
8. Dynamic Programming — hard to learn, medium return
9. Divide and Conquer / Trie / Union Find / Greedy — low return, do last
